# React Machine Coding Questions

A collection of **React machine coding interview problems** implemented using **React + TypeScript**.

This repository is meant for practicing **frontend machine coding rounds commonly asked in interviews**. These challenges help improve component design, state management, and problem-solving skills in React.

🔗 Live Demo  
https://react-machine-coding-questions.netlify.app/

---

## Problems

The repository contains implementations of the following React machine coding questions:

- Todo List
- Modal
- Star Rating
- Drag & Drop Board
- Form Validation
- Date Picker
